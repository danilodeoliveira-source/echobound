ECHOBOUND vMetaModel2027 — DELUXE EDITION

Build estático para GitHub Pages/Hostinger.

NOVO COMÉRCIO DELUXE
- Comprar itens com validação de saldo e limite de 99 unidades.
- Vender itens por 60% do preço base.
- Vender item equipado remove o equipamento automaticamente.
- Equipar e remover arma, armadura e relíquia.
- Usar consumíveis em fase: Poção de Vida, Elixir do Eco e Frasco de Velocidade.
- Histórico das últimas transações e resumo da carteira.
- Estado salvo em localStorage com anti-tamper de cliente.

CONTEÚDO
- 20 regiões, 500 fases, 2.000 encontros de chefes.
- Combate, combo, dash, parry, Eco, Ressonância, Sobrecarga.
- XP, níveis, missões, conquistas e estilos de combate.
- Lobby branco clean com serviços e informações.
- Perfis ULTRA/8K adaptativos quando o navegador/GPU suportar WebGL.

LIMITES DE SEGURANÇA
Este build é client-side. Para uma economia pública realmente resistente a edição de memória/localStorage, use backend autoritativo com validação no servidor.
